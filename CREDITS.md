- **SylEleuth / Sylwia Ptasinska** and contributors: [Gruvbox Plus Icon Pack](https://github.com/SylEleuth/gruvbox-plus-icon-pack), GPL-3.0 and inherited artwork licenses in `LICENSES/gruvbox-plus`.

Original cursor sources and build recipe are in `SOURCES/capitaine-cursors`.

The theme combines existing artwork. GTK CSS removes a dangling reference to the absent thumbnail-frame.png and retains its existing solid border. Directory names, icon inheritance and theme metadata were adapted to avoid replacing existing themes. Icon drawings are the project's already customized versions. Original notices and embedded copyrights remain. `LICENSE` supplies GPL-3.0 for this integration; it does not override component licenses or trademark rights.
