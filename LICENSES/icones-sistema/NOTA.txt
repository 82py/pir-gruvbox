# Recolored system icons / Ícones de sistema recoloridos

The recolored XApp icons derive from the original artwork in `/usr/share/icons/hicolor/scalable/actions`. Their geometry and original SVG copyright metadata were preserved. Pir (82py) directed the color work with OpenAI Codex assistance on 21 October 2026. Original artwork and notices are included under `LICENSES/icones-sistema`; the complete icon theme inherits `Pir-Gruvbox-Base`, derived from Gruvbox Plus. See the root `CREDITS.md` and component licenses for attribution and terms.
